Privacy policy

Last updated November 5, 2026

gws CLI is a personal tool used only by its owner to manage their own Google Calendar.

What data it accesses

With the owner's permission, it reads and changes calendar events and calendars in the owner's own Google account, using the Google Calendar API. It also reads the account's email address and basic profile to identify which account is signed in.

How the data is used and stored

  • Calendar data is used only to show, create, change or remove the owner's own events when the owner asks.
  • Sign-in credentials are stored encrypted on the owner's own computer. No data is sent to any server run by this app, because there is none.
  • No data is sold, shared with third parties, used for advertising, or used to train AI models.

Google API Services User Data Policy

gws CLI's use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
